## 📌 Preentrega 5

> **Nota:** Para esta preentrega se implementó la base de datos **RetailPro**, siguiendo el modelo relacional definido en las preentregas 1 (Brief del Proyecto) y 2 (Modelo Entidad–Relación). Esta decisión se tomó debido a que la consigna del Módulo 5 requiere entidades y atributos como **Clientes, Productos, Territorios, Segmento, Región y Canal**, los cuales no forman parte de la base de datos simplificada desarrollada en la Preentrega 3.

**Archivos:**

- `RetailPro_M3_Creacion_Base.sql`
- `m5_consultas_joins.sql`

La preentrega incluye consultas utilizando:

- INNER JOIN
- LEFT JOIN
- UNION ALL

para integrar la información de clientes, productos, territorios y ventas en una única vista de análisis.

---

## ▶️ Cómo ejecutar la Preentrega 5

Para ejecutar correctamente las consultas es necesario seguir este orden:

1. Ejecutar `RetailPro_M3_Creacion_Base.sql`.
2. Seleccionar la base de datos **RetailPro**.
3. Ejecutar `m5_consultas_joins.sql`.

Este orden garantiza que las tablas y los datos necesarios se encuentren disponibles antes de ejecutar las consultas del módulo.

## 🗄️ Modelo de datos

La base de datos **RetailPro** está compuesta por las siguientes tablas principales:

- Clientes
- Productos
- Territorios
- Ventas

Las relaciones entre ellas permiten realizar análisis sobre:

- Ventas por cliente.
- Ventas por producto.
- Ventas por región.
- Ventas por canal.
- Segmentación de clientes.
- Rendimiento de productos.
