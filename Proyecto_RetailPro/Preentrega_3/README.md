## Descripción

Este proyecto corresponde a la Preentrega 3 del curso Data Analytics de Coderhouse.

Se desarrolló un script SQL para la creación de la base de datos **Ventas_Tech_DB**, incluyendo:

- Creación de tablas (DDL).
- Definición de claves primarias y foráneas.
- Restricciones de integridad.
- Carga inicial de datos (DML).
- Consultas de verificación.

## Estructura

- `ventas_tech_db.sql` → Script completo de la base de datos.

## Base de datos

**Ventas_Tech_DB**

Tablas creadas:

- categorias
- clientes
- productos
- ventas

## Tecnologías utilizadas

- PostgreSQL 18
- pgAdmin 4
