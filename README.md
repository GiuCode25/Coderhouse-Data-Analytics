# 📊 Data Analytics - Coderhouse

Repositorio destinado a almacenar las prácticas, ejercicios y entregas desarrolladas durante el curso **Data Analytics** de **Coderhouse**.

A lo largo del curso se trabajan conceptos de bases de datos, SQL y análisis de información, aplicados en actividades prácticas y en un proyecto integrador que evoluciona módulo a módulo.

---

# 📖 Objetivo

Documentar el proceso de aprendizaje mediante el desarrollo de ejercicios y proyectos que permitan aplicar los principales conceptos de:

- Diseño de bases de datos relacionales.
- Lenguaje SQL (DDL, DML y DQL).
- Modelado de datos.
- Consultas para análisis de negocio.
- Preparación de datos para su posterior análisis en Power BI.

---

---

# 📚 Contenido

Durante el curso se desarrollan actividades relacionadas con:

- Consultas SQL.
- Creación y administración de bases de datos.
- Diseño de modelos relacionales.
- Restricciones de integridad.
- Inserción y manipulación de datos.
- Consultas de agregación y agrupamiento.
- JOIN (INNER, LEFT, RIGHT y FULL).
- UNION y UNION ALL.
- Preparación de datos para Power BI.

---

# 🗂️ Proyecto Integrador

El repositorio incluye un **Proyecto Integrador**, desarrollado de manera incremental a lo largo del curso.

En cada preentrega se incorporan nuevos conocimientos y funcionalidades, permitiendo construir una solución completa para el análisis de datos mediante SQL y, posteriormente, Power BI.

Actualmente el proyecto incluye:

- ✔️ Diseño del modelo de datos.
- ✔️ Creación de la base de datos.
- ✔️ Definición de restricciones.
- ✔️ Carga inicial de datos.
- ✔️ Consultas de análisis de negocio.
- ✔️ Consultas utilizando JOIN y UNION ALL.

El proyecto continuará ampliándose en los próximos módulos con la integración en **Power BI** para el desarrollo de dashboards e indicadores.
