# Análisis de Datos - Coderhouse

Repositorio creado para almacenar las prácticas, ejercicios y entregas realizadas durante el curso **Análisis de Datos** de Coderhouse.

## Objetivo

Documentar el aprendizaje y la evolución durante el curso mediante ejercicios prácticos utilizando SQL Server, SQL y herramientas de análisis de datos.

## Contenido

Este repositorio incluye:

- Ejercicios prácticos de SQL.
- Scripts de creación y diseño de bases de datos.
- Actividades y entregas de cada módulo.
- Prácticas de modelado y consultas sobre bases de datos.

## Tecnologías utilizadas

- SQL Server 2025 Express
- SQL Server Management Studio (SSMS)
- SQL
- Git
- GitHub

## Organización

Los archivos se nombran según el módulo y la unidad correspondiente para mantener una estructura clara.

Ejemplo:

```
modulo2_unidad1_diseno.sql
modulo2_unidad2.sql
modulo3_unidad1.sql
```
